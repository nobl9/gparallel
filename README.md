This is Nobl9's fork of [karolba/gparallel](https://github.com/karolba/gparallel).
It exists to fix a defect where gparallel could exit successfully without waiting
for the last queued commands or printing their output. Releases of this fork are
built by the workflow that runs when a `v*` tag is pushed. Install one with
`go install github.com/nobl9/gparallel@v1.9.1`, or download `gparallel-x86_64`
from the [releases page](https://github.com/nobl9/gparallel/releases).
Upstream continues as karolba/pinip, which has no releases; the banner below is
upstream's.
